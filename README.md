# Security Testing Report: OWASP Juice Shop

## Project Overview
This repository contains a comprehensive security assessment of the OWASP Juice Shop application. 

## Vulnerabilities Found
* **SQL Injection:** Found in the login field.
* **Broken Authentication:** Weak password requirements.
* **XSS:** Reflected XSS in the search bar.

## Tools Used
* Burp Suite
* OWASP ZAP
* Python scripts for automation

## Conclusion
The application requires several patches to ensure user data security.
